# EDA on Retail Sales Data

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on retail sales data to identify sales patterns, customer behaviour, and useful business insights.

## Objectives

- Analyse the retail sales dataset
- Check data shape, data types, and missing values
- Calculate descriptive statistics
- Analyse monthly and quarterly sales trends
- Analyse customer age groups and gender
- Identify top-selling product categories
- Analyse revenue by product category
- Create a correlation heatmap
- Find additional business insights
- Provide actionable business recommendations

## Dataset

The project uses a retail sales dataset containing information about customers, products, sales, and transaction details.

Important fields include:
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Methodology

### 1. Data Loading

The dataset is loaded using Pandas and its basic structure is analysed.

### 2. Descriptive Statistics

Mean, median, mode, and standard deviation are calculated for numerical variables.

### 3. Time Series Analysis

Monthly and quarterly sales trends are analysed using line charts.

### 4. Customer Demographics

Customer age groups and gender distribution are analysed.

### 5. Product Analysis

Top-selling product categories are identified based on quantity sold, and revenue by product category is analysed using a bar chart.

### 6. Correlation Analysis

A correlation heatmap is created to understand relationships between numerical variables.

### 7. Additional Visualization

Sales by gender are visualized to identify differences in sales contribution.

## Key Insights

- Identified monthly and quarterly sales trends
- Analysed customer age groups and gender distribution
- Identified high-demand product categories
- Compared revenue generated by product categories
- Found relationships between numerical variables
- Analysed sales contribution by gender

## Conclusion

The EDA provides useful insights into sales performance, customer demographics, product demand, and relationships between numerical variables. These findings can help businesses improve inventory management, marketing strategies, and sales decisions.
