# Google Play Store Data Analysis

## Project Overview

This project analyses Google Play Store apps and user reviews using Python. The goal is to understand app categories, ratings, installs, pricing, and user sentiment.

## Objectives

- Analyse app distribution across categories
- Analyse app ratings
- Study installs and app size
- Compare free and paid apps
- Analyse paid app prices
- Analyse user sentiment
- Compare sentiment across categories
- Create visualisations

## Dataset

The project uses Google Play Store app data and user review data obtained from Kaggle.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VADER Sentiment Analysis
- Plotly
- Jupyter Notebook

## Data Cleaning

- Removed duplicate records
- Handled missing values
- Converted installs and price into numeric values
- Prepared reviews for sentiment analysis

## Analysis Performed

### Category Analysis
Analysed the number of apps in different categories.

### Rating Analysis
Studied app ratings and average ratings.

### Pricing Analysis
Compared free and paid apps and analysed the price distribution of paid apps.

### Sentiment Analysis
Classified user reviews as Positive, Negative, or Neutral using VADER.

### Sentiment by Category
Compared user sentiment across different app categories.

### Visualisation
Created charts and visualisations to communicate the findings.

## Key Insights

- Free apps are more common than paid apps.
- Some categories contain significantly more apps than others.
- Most paid apps are available at lower prices.
- User reviews provide useful information about customer satisfaction.

## Conclusion

This project demonstrates how Python, data analysis, and visualisation techniques can be used to analyse the Google Play Store and understand app performance and user feedback.
