# Unveiling the AndroidApp Market(Google Play Store Data Analysis)

## Project Overview

This project analyses Google Play Store apps and user reviews using Python.
The aim is to understand app categories, ratings, installs, size, pricing,
revenue, and user sentiment.

## Objectives

- Analyse app distribution across categories.
- Analyse app ratings and average ratings.
- Study the relationship between app size and installs.
- Compare free and paid apps.
- Analyse the price distribution of paid apps.
- Estimate revenue by category.
- Perform sentiment analysis on user reviews.
- Compare sentiment across app categories.
- Create an interactive visualisation using Plotly.

## Dataset

The project uses Google Play Store app data and user review data obtained
from Kaggle.

The datasets contain information such as app name, category, rating, size,
installs, price, and user reviews.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VADER Sentiment Analysis
- Plotly
- Jupyter Notebook

## Data Cleaning

The following data cleaning operations were performed:

- Removed duplicate apps.
- Handled missing values.
- Converted Installs into numeric values.
- Converted Price into numeric values.
- Prepared user reviews for sentiment analysis.

## Analysis Performed

### 1. Category Analysis

Analysed the number of apps in each category to identify popular and highly
saturated categories.

### 2. Ratings Analysis

Analysed the distribution of app ratings and calculated average ratings
across categories.

### 3. Size and Installs Analysis

Used a scatter plot to study the relationship between app size and number
of installs.

### 4. Pricing Analysis

Compared free and paid apps, analysed the price distribution of paid apps,
and estimated revenue by category.

### 5. Sentiment Analysis

Used VADER to classify user reviews into:

- Positive
- Negative
- Neutral

### 6. Sentiment by Category

Compared positive, negative, and neutral user sentiment across different
app categories.

### 7. Interactive Visualisation

Created an interactive visualisation using Plotly to explore app categories.

## Key Insights

- Free apps are more common than paid apps.
- Popular categories have greater competition.
- Ratings and user sentiment provide useful information about user satisfaction.
- Pricing, installs, ratings, and sentiment can help developers make better
  decisions when launching a new app.

## Conclusion

This project demonstrates how Python-based data analysis and visualisation
can be used to understand Google Play Store apps and user reviews. The
insights can help developers choose suitable categories, pricing strategies,
and features while improving user satisfaction.
